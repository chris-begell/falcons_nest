This is a team selection and score calculating program written in Python for Euchre tournaments. Player names are stored in a json file. Teams are randomly selected from a list of selected players.
If there is an uneven number of players selected, the program gives a warning. After teams are generated, a new window with a score grid opens with the teams displayed on the left and the correct number of 
entry fields for the number of games that will need to be played during a single elimination tournament. Scores are totaled automatically. Currently there are no restraints on the scores, allowing adatation to other games.
This program is free to use and modify.
